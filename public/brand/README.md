# Logo officiel BEM THE LIONS

Déposer ici le fichier du logo officiel sous le nom :

    logo-bem-the-lions.png

(PNG à fond transparent recommandé, carré, 512×512 px minimum.)

Si le fichier porte un autre nom ou une autre extension (.svg, .webp…), modifier
`logoSrc` dans `src/config/brand.ts`. Le logo est alors utilisé automatiquement
partout : splash screen, navbar, accueil, inscription, carte candidat (et son PNG
téléchargeable), pages de résultat, dashboard admin, footer et favicon.
